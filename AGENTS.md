# Project agent guidance

## UI and UX work

For requests that design, review, or change the visual interface, interaction, accessibility, responsive layout, typography, color, navigation, or forms, use the project-local `ui-ux-pro-max` skill at `.agents/skills/ui-ux-pro-max/SKILL.md`.

Use its `scripts/search.py` with the smallest relevant query before making design decisions. Keep the portfolio's existing constraints: no hard gradients, icon libraries, pure-white backgrounds, drop shadows, neon, or animated arrows.
