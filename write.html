Connect this browser

Publishing saves your post straight into the website's GitHub repository. To allow that, create a token that can only change this one repository, then paste it below. It is stored only in this browser.

  1. Open GitHub → New fine-grained token.
  2. Name it Website writer and pick an expiry (for example, one year).
  3. Under Repository access, choose Only select repositories → Arun949/Arun949.github.io.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else as it is.
  5. Click Generate token, copy it, and paste it here.
